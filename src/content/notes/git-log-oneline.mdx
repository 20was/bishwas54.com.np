---
title: 'Make git log readable with --oneline'
description: 'The default git log is a wall of text. One flag fixes it.'
datePublished: 2026-08-08
tags: ['git', 'tools']
---

The default `git log` shows a paragraph per commit. For a quick look at
history, that's noise. This is better:

```sh
git log --oneline
```

One line per commit: short ID + message. Add `--graph` to see branches drawn
in ASCII:

```sh
git log --oneline --graph --all
```

Small flag, big quality-of-life win. If you only remember one `git log`
variant, make it this one.
